# Campus videos

Place MP4 files here for campus page heroes:

| File | Campus |
|------|--------|
| `rajanpur-campus.mp4` | Misbah Campus, Rajanpur |
| `fazilpur-campus.mp4` | Hamid Campus, Fazilpur |
| `kotmithan-campus.mp4` | Abul Rehman Campus, Kot Mithan |

Update paths in `includes/campus-data.php` when files are added. Until then, campus pages show the poster image from `assets/images/image1.png` (etc.) via the `<video poster="...">` attribute.
